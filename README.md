# Bright-Coffee-shop

This repository is the result for the Bright Coffee Shop presentaion.
SQL & Data Analytics Portfolio: Coffee Shop Case Study & Fundamentals
Project Overview
This repository showcases a combination of data analysis and SQL proficiency. It features a large-scale analysis of a retail coffee business ("Bright Coffee Shop") and a series of structured exercises demonstrating core SQL capabilities, from basic aggregate functions to complex conditional logic.

Part 1: Bright Coffee Shop Analysis (Case Study)
This project analyzes transaction-level data to optimize store operations and identify revenue drivers.

Data Scope
The dataset includes over 149,000 transactions with the following attributes:

Transactions: Date, time, and quantity.

Geography: Store locations across Hell's Kitchen, Astoria, and Lower Manhattan.

Inventory: Product categories (Coffee, Tea, Drinking Chocolate), types, and specific details.

Key Performance Indicators (KPIs)
Total Revenue by Store: Hell's Kitchen leads performance with R3 858 963,55 in total revenue, followed by Astoria (R3 789 338,08).

Product Performance: Sustainably Grown Organic Lg (Drinking Chocolate) and Latte Rg are among the top-selling products by revenue.

Temporal Trends: Revenue is tracked across months, days of the week, and hourly intervals to identify peak traffic periods.

Part 2: SQL Fundamentals (Aggregates & Grouping)
This section demonstrates the use of SQL to extract meaningful insights from an employee database (employees_db).

Core Technical Skills:
Aggregate Functions: Calculating total payroll (SUM), headcounts (COUNT), and average salaries (AVG).

Data Grouping: Analyzing metrics by department and city to identify organizational trends.

Filtering Aggregates: Using the HAVING clause to isolate departments where total salary expenditure exceeds R1 631,620.

Part 3: Advanced SQL Logic (CASE Statements)
This module focuses on data transformation and classification using CASE statements to create dynamic reporting categories.

Logic Implementation Examples:
Financial Tiering: Classifying products as 'Expensive', 'Mid-range', or 'Budget' based on price points.

Performance Labeling: Assigning letter grades (A-F) based on student scores and attendance status (e.g., 'Excellent' for ≥90%).

Inventory Management: Flagging stock status as 'Out of Stock', 'Low Stock', or 'In Stock' based on quantity.

Operational Flags: Determining discount eligibility based on payment method and transaction amount.

Repository Structure
Data/: Raw CSV files including the Bright Coffee Shop transaction log.

Dashboards/: Excel-based visualizations for revenue and product performance.

SQL_Queries/: Structured scripts for aggregate functions and CASE statement logic.
